# Stan P — Graphic Designer Portfolio

Static portfolio site (plain HTML/CSS/JS, no build step).

- `index.html` — page layout and copy
- `works.js` — the project list; add an entry here to add a piece
- `assets/img/` — artwork (from stanlyp9.wordpress.com)
- `assets/video/` — WebGL project recording + poster

## Run locally

Open `index.html` in a browser, or serve the folder:

    npx serve .

## Publish with GitHub Pages

Repo Settings → Pages → Deploy from branch → `main` / root.
